# 운영·인수인계 안내

이 앱을 맡게 된 분이 읽는 문서입니다. 코드를 몰라도 아래 대부분은 구글 시트에서 고치면 됩니다.

## 매일 하는 일
- 아침에 앱을 열면 **브리핑**이 나옵니다. 위에서부터 **공문 접수 확인 → 오늘(연체·내줄 것·반납·교실 사용) → 다음 대여** 순서입니다.
- 공문이 오면 브리핑의 **공문 접수 확인**에서 공문번호를 적고 **공문 왔어요**를 누릅니다. (센터 지도교사처럼 공문이 없는 건은 번호를 비운 채로 눌러도 사라집니다.)
- 전화로 받은 대여는 **대여 → + 새 대여**에서 입력합니다. 날짜가 오늘이면 **지금 대여**, 아니면 **대여 예약 저장**을 누릅니다.

## 센터 프로그램 교구 잡기
주말창의·방학 프로그램처럼 센터에서 쓰는 교구는 **교구대여 → + 센터 프로그램**에서 미리 잡아 둡니다.
- 프로그램 이름, 시작일, 끝나는 날, 교구를 고릅니다. 교구마다 기본 **18개**(정원 16명 + 여유 2)가 자동으로 들어가고, 고칠 수 있습니다.
- 시작 **7일 전부터 끝난 7일 뒤까지**(수업 준비와 끝난 뒤 점검) 잡아 둔 교구는 외부에 대여할 수 없습니다.
- 서명이나 반납 확인은 없습니다. 기간이 끝나면 저절로 풀립니다.
- 주 1회 10회처럼 여러 번 하는 프로그램은 **첫 날부터 마지막 날까지 한 번에** 넣습니다. (끝나는 날의 `+9주` 버튼)
- 대여 문의가 오면 **교구대여 → 교구 가능 여부 조회**에서 교구와 기간을 넣어 바로 답할 수 있습니다.
- 기본 수량(18)과 앞뒤 기간(7일)은 시트 `설정` 탭의 `센터사용기본수량`, `센터사용여유일수`에서 바꿉니다.

## 구글 시트에서 고치는 것
| 하고 싶은 일 | 어디서 |
|---|---|
| 직원 추가·삭제 | `직원` 탭 (이메일과 이름) — 구글 클라우드 OAuth 동의 화면의 **테스트 사용자**에도 이메일을 넣어야 합니다 |
| 교실 추가·순서 변경 | `교실` 탭 (교실, 약자, 순서, 수업우선에 Y) |
| 보관위치 목록 | `설정` 탭 `보관위치` (쉼표로 구분) |
| 반납 기본 일수 | `설정` 탭 `반납기본일수` |
| 센터 프로그램 기본 수량·앞뒤 기간 | `설정` 탭 `센터사용기본수량`, `센터사용여유일수` |
| 연락처 보관 기간 | `설정` 탭 `연락처보관일수` (기본 365일) |
| 공개 목록의 센터 전화번호 | `설정` 탭 `센터전화` |
| 물품 정보 직접 고치기 | `물품` 탭 (앱에서 고치는 것이 더 안전합니다) |

고친 뒤에는 앱의 **더보기 → 최신으로 새로고침**을 누르세요.

> 시트의 맨 윗줄(제목)은 고치거나 지우지 마세요. 앱이 그 이름으로 칸을 찾습니다. 열을 더하는 것은 괜찮습니다.

## 해마다 하는 일
- **학교 목록**: 학교가 생기거나 없어졌으면 `apps/inventory/tools/make_schools.py`로 `docs/inventory/schools.json`을 다시 만들어 올립니다.
- **연도 정리**: 시트가 느려질 정도로 쌓이면(보통 몇 년 뒤) `대여`·`대여품목`·`교실예약`·`변경기록`의 오래된 줄을 새 시트 파일로 옮겨 보관합니다.
- **정기 점검**: 학기말에 **더보기 → 점검 → + 새 점검 회차 시작**으로 물품과 교실을 확인합니다.

## 개인정보
- 학생·학부모 정보는 받지 않습니다. 선생님 이름·연락처는 대여 기록에만 있고, 반납 완료(또는 교실 사용일)로부터 설정한 기간(기본 1년)이 지나면 연락처가 자동으로 지워집니다.
- 서명과 반납 사진은 구글 드라이브의 비공개 폴더(`창의센터앱_서명(비공개)`, `창의센터앱_반납사진(비공개)`)에 저장됩니다. **공유 설정을 바꾸지 마세요.**
- 외부 공개 목록에는 `외부공개`를 체크한 교구의 이름과 사진만 나옵니다.

## 소유자 옮기기 (센터 공용 계정으로 이전할 때)
개인 계정으로 시작했다면 아래를 한 번에 옮깁니다. 담당자가 바뀔 때도 같은 순서입니다.
1. **구글 시트**: 공유 → 새 소유자를 선택해 소유권 이전
2. **드라이브 폴더 2개**(서명·반납사진): 각각 공유 → 소유권 이전
3. **Apps Script**: 시트에 연결된 스크립트라 시트와 함께 넘어갑니다. 새 소유자가 **배포 → 새 배포**를 다시 하고 `config.js`의 `API_URL`을 새 주소로 바꿉니다. 스크립트 속성 `CLIENT_ID`도 다시 넣습니다.
4. **GitHub 저장소**: Settings → General → 맨 아래 Danger Zone → **Transfer ownership**
5. **구글 로그인 설정(CLIENT_ID)**: 구글 클라우드 프로젝트의 소유자를 추가해 둡니다.

## 나중에 붙이기 쉬운 것
- **QR 라벨**: 물품마다 관리번호(`S-001`)가 이미 있어서, 라벨만 인쇄해 붙이면 됩니다.
- **직원별 권한**: `직원` 탭에 `역할` 칸이 이미 있습니다.
- **물품의 세부 위치**: `물품` 탭 `세부위치` 칸이 이미 있습니다.

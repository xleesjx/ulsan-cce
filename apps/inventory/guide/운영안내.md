# 운영·인수인계 안내

이 앱을 맡게 된 분이 읽는 문서입니다. 코드를 몰라도 아래 대부분은 구글 시트에서 고치면 됩니다.

## 매일 하는 일
- 아침에 앱을 열면 **브리핑**이 나옵니다. 위에서부터 **공문 접수 확인 → 오늘(연체·내줄 것·반납·교실 사용) → 다음 대여** 순서입니다.
- 공문이 오면 브리핑의 **공문 접수 확인**에서 공문번호를 적고 **공문 왔어요**를 누릅니다. (센터 지도교사처럼 공문이 없는 건은 번호를 비운 채로 눌러도 사라집니다.)
- 전화로 받은 대여는 **교구대여 → + 새 대여**(오른쪽 위)에서 입력합니다. 날짜가 오늘이면 **지금 대여**, 아니면 **대여 예약 저장**을 누릅니다.

## 교구대여·교실대여 화면의 탭
화면 위쪽 탭은 **하려는 일** 이름으로 나뉩니다.

| 메뉴 | 탭 | 하는 일 |
|---|---|---|
| 교구대여 | **문의 확인** (처음 화면) | 전화 문의 "몇 일부터 몇 일까지 몇 대?"에 답하기 |
| 교구대여 | **처리할 것** | 위에서부터 연체 → 오늘 반납 받을 것 → 오늘 내줄 것 → 곧 다가오는 예약(7일) → 대여 중·그 뒤 예약. 맨 아래 **지난 기록**에서 반납 완료·취소 건을 봅니다 |
| 교구대여 | **월간 계획** | 한 달 달력(내주기·반납·센터 프로그램)과 **이번 달 센터 프로그램**, **+ 센터 프로그램** |
| 교실대여 | **처리할 것** | 공문 접수 확인(외부 대여) → 오늘 사용 → 곧 다가오는 예약 |
| 교실대여 | **월간 계획** (처음 화면) | 한 달 달력. 위쪽에서 교실별로 걸러 볼 수 있습니다 |

- **처리할 것** 탭 옆의 빨간 숫자는 지금 바로 할 일 수입니다(교구: 연체·오늘 반납·오늘 내주기, 교실: 공문 확인 전 외부 대여).
- 내주기·반납·예약 저장을 마치면 **처리할 것** 탭으로 돌아옵니다.

## 접속 (잠금 화면과 관리자 메뉴)
- 앱을 열면 휴대폰 잠금 화면처럼 **숫자 4자리 접속 코드**를 넣습니다. 구글 로그인은 하지 않습니다.
  - 코드는 기기에 저장하지 않아서 **앱을 열 때마다** 넣습니다.
  - 다른 앱으로 **5분 넘게** 나가 있었거나 **15분 동안** 아무것도 누르지 않으면 다시 잠깁니다. **더보기 → 지금 잠그기**로 바로 잠글 수도 있습니다.
  - 다시 풀면 보던 화면으로 돌아갑니다.
- 코드를 **10번 틀리면 10분 동안 모든 기기에서** 입력이 막히고, 시트 `변경기록` 탭에 "접속 코드 잠김"이 남습니다. 자주 보이면 코드를 바꿔 주세요.
- **관리자 메뉴**(더보기 → 관리자 메뉴)에 들어갈 때만 **직원 탭에 등록된 구글 계정**으로 로그인합니다. 확인은 30분 동안 유지됩니다.
  - 관리자 메뉴에서 하는 일: 접속 코드 바꾸기, 직원 이메일 보기, 엑셀 내려받기(연락처 포함), 구글 시트·Apps Script 열기, 서버 코드 업데이트
- **접속 코드 바꾸기**: 관리자 메뉴의 [앱 접속 코드]에서 바꾸거나, 시트 메뉴 **창의센터 앱 → 접속 코드 정하기**에서 바꿉니다.
  - 바꾸면 코드로 들어와 있던 모든 기기가 바로 잠깁니다. 직원에게 새 코드를 알려 주세요.
  - 0000, 1234처럼 쉬운 코드는 쓸 수 없습니다. 직원이 바뀌거나 코드가 새어 나갔다고 생각되면 바꿔 주세요.
  - 태블릿에 코드를 써 붙여 두지 마세요.
- **처리 직원**: 내주기·반납·새 대여·교실 예약 화면 아래의 [처리 직원] 칸에서 이름을 고르거나 직접 적습니다.
  - 직원 탭의 이름이 버튼으로 나오고, 그 기기에서 마지막으로 고른 이름이 자동으로 채워집니다.
  - 고른 이름이 `변경기록`, 대여의 `접수직원`·`내준직원`, 교실예약의 `등록자`에 남습니다.
- 기기를 잃어버렸을 때는 시트 메뉴 **창의센터 앱 → 모든 기기에서 로그아웃**을 누르세요.

## 전화 문의에 답하기 (교구 가능 여부)
"A교구 며칠부터 며칠까지 몇 대 빌릴 수 있나요?" 전화가 오면 **교구대여 → 문의 확인** 탭을 엽니다(교구대여를 누르면 처음 나오는 화면).
1. **교구**를 검색해서 고르고(초성 가능), **빌리는 날 / 반납하는 날 / 수량**을 넣습니다.
2. 바로 **"가능합니다"** 또는 **"N대는 어려워요 (최대 M대)"**가 나옵니다. 아래에 그 기간을 막고 있는 일정(어느 학교, 센터 프로그램, 수리 대기)이 이유로 나옵니다.
3. 가능하면 **[이 내용으로 대여 예약]**을 눌러 학교와 선생님만 입력하면 됩니다.
- 결과에는 **교구 사진과 설명**이 함께 나와서 모양을 확인할 수 있습니다. 검색 후보 목록에도 작은 사진이 보여서 비슷한 이름을 구분할 수 있습니다.
- **앞뒤 한 달 이내 다른 대여·사용 계획**이 목록으로 바로 나옵니다. 반납한 뒤 점검하고, 파손·분실 때 추가 구입할 여유가 있는지 참고하는 용도입니다.
  - 바로 이어지는 대여(사이에 빈 날이 없음)는 **"여유 없음"**, 일주일 안이면 **"여유 N일"**로 표시하고, 위쪽에 경고 안내가 나옵니다.
  - 연체 중인 대여는 **"연체 중"**으로 표시하고 오늘 돌아온다고 보고 계산합니다.
- 한 달 달력은 처음부터 함께 보이고, **문의한 기간이 파란 테두리**로 표시됩니다.
- 교구를 고르지 않고 날짜만 넣으면 **그 기간에 수량이 줄어드는 교구**만 목록으로 나옵니다. 나머지는 전량 가능합니다.
- **[이 교구 한 달 달력 보기]**(물품 상세에도 있음)는 날짜별 남은 수량을 숫자로 보여 줍니다. 날짜를 누르면 그날로 확인합니다.
- 여러 날 기간은 **그 기간 중 하루에 가장 많이 나가 있는 수량**을 기준으로 계산합니다. 서로 겹치지 않는 대여는 더하지 않습니다.
- **반납 예정일 당일**은 아직 나가 있는 것으로 계산하고, 결과에 "그날 반납 예정 N개"를 따로 알려 줍니다. 아침에 돌려받는다면 그만큼 더 빌려줄 수 있습니다.
- **연체 중인 교구**는 돌아온 것으로 계산하고, 따로 경고를 보여 줍니다.

## 센터 프로그램 교구 잡기
주말창의·방학 프로그램처럼 센터에서 쓰는 교구는 **교구대여 → 월간 계획 → + 센터 프로그램**에서 미리 잡아 둡니다.
- 프로그램 이름, 시작일, 끝나는 날, 교구를 고릅니다. 교구마다 기본 **18개**(정원 16명 + 여유 2)가 자동으로 들어가고, 고칠 수 있습니다.
- 시작 **7일 전부터 끝난 7일 뒤까지**(수업 준비와 끝난 뒤 점검) 잡아 둔 교구는 외부에 대여할 수 없습니다.
- 서명이나 반납 확인은 없습니다. 기간이 끝나면 저절로 풀립니다.
- 주 1회 10회처럼 여러 번 하는 프로그램은 **첫 날부터 마지막 날까지 한 번에** 넣습니다. (끝나는 날의 `+9주` 버튼)
- 대여 문의가 오면 **교구대여 → 문의 확인**에서 교구와 기간을 넣어 바로 답할 수 있습니다.
- 기본 수량(18)과 앞뒤 기간(7일)은 시트 `설정` 탭의 `센터사용기본수량`, `센터사용여유일수`에서 바꿉니다.

## 구글 시트에서 고치는 것
| 하고 싶은 일 | 어디서 |
|---|---|
| 직원 추가·삭제 | `직원` 탭 (이메일과 이름) — 구글 클라우드 OAuth 동의 화면의 **테스트 사용자**에도 이메일을 넣어야 합니다 |
| 교실 추가·순서 변경 | `교실` 탭 (교실, 약자, 순서, 수업우선에 Y) |
| 보관위치 목록 | `설정` 탭 `보관위치` (쉼표로 구분) |
| 반납 기본 일수 | `설정` 탭 `반납기본일수` |
| 앱 접속 코드 | 앱의 **관리자 메뉴** 또는 시트 메뉴 **창의센터 앱 → 접속 코드 정하기** |
| 센터 프로그램 기본 수량·앞뒤 기간 | `설정` 탭 `센터사용기본수량`, `센터사용여유일수` |
| 연락처 보관 기간 | `설정` 탭 `연락처보관일수` (기본 365일) |
| 공개 목록의 센터 전화번호 | `설정` 탭 `센터전화` |
| 물품 정보 직접 고치기 | `물품` 탭 (앱에서 고치는 것이 더 안전합니다) |

고친 뒤에는 앱의 **더보기 → 최신으로 새로고침**을 누르세요.

> 시트의 맨 윗줄(제목)은 고치거나 지우지 마세요. 앱이 그 이름으로 칸을 찾습니다. 열을 더하는 것은 괜찮습니다.

## 해마다 하는 일
- **학교 목록**: 학교가 생기거나 없어졌으면 `apps/inventory/tools/make_schools.py`로 `docs/inventory/schools.json`을 다시 만들어 올립니다.
- **연도 정리**: 시트가 느려질 정도로 쌓이면(보통 몇 년 뒤) `대여`·`대여품목`·`교실예약`·`변경기록`의 오래된 줄을 새 시트 파일로 옮겨 보관합니다.
- **정기 점검**: 학기말에 **더보기 → 점검 → + 새 점검 회차 시작**으로 물품과 교실을 확인합니다.

## 개인정보
- 학생·학부모 정보는 받지 않습니다. 선생님 이름·연락처는 대여 기록에만 있고, 반납 완료(또는 교실 사용일)로부터 설정한 기간(기본 1년)이 지나면 연락처가 자동으로 지워집니다.
- 서명과 반납 사진은 구글 드라이브의 비공개 폴더(`창의센터앱_서명(비공개)`, `창의센터앱_반납사진(비공개)`)에 저장됩니다. **공유 설정을 바꾸지 마세요.**
- 외부 공개 목록에는 `외부공개`를 체크한 교구의 이름과 사진만 나옵니다.

## 소유자 옮기기 (센터 공용 계정으로 이전할 때)
개인 계정으로 시작했다면 아래를 한 번에 옮깁니다. 담당자가 바뀔 때도 같은 순서입니다.
1. **구글 시트**: 공유 → 새 소유자를 선택해 소유권 이전
2. **드라이브 폴더 2개**(서명·반납사진): 각각 공유 → 소유권 이전
3. **Apps Script**: 시트에 연결된 스크립트라 시트와 함께 넘어갑니다. 새 소유자가 **배포 → 새 배포**를 다시 하고 `config.js`의 `API_URL`을 새 주소로 바꿉니다. 스크립트 속성 `CLIENT_ID`도 다시 넣습니다.
4. **GitHub 저장소**: Settings → General → 맨 아래 Danger Zone → **Transfer ownership**
5. **구글 로그인 설정(CLIENT_ID)**: 구글 클라우드 프로젝트의 소유자를 추가해 둡니다.

## 나중에 붙이기 쉬운 것
- **QR 라벨**: 물품마다 관리번호(`S-001`)가 이미 있어서, 라벨만 인쇄해 붙이면 됩니다.
- **직원별 권한**: `직원` 탭에 `역할` 칸이 이미 있습니다.
- **물품의 세부 위치**: `물품` 탭 `세부위치` 칸이 이미 있습니다.

# 창의센터 물품·시설 관리 앱 설치 안내

처음 한 번만 하면 됩니다. 약 40분 걸립니다. 순서대로 따라 해 주세요.
`weekend-checker`를 설치해 보셨다면 거의 같은 순서입니다.

준비물: 구글 계정, GitHub 계정(`xleesjx`), 이 저장소(`ulsan-cce`)의 파일들

```
[웹 화면: GitHub Pages]  →  [저장·검사: Apps Script]  →  [구글 시트 + 드라이브]
```

> 구글 로그인 설정(CLIENT_ID)은 `weekend-checker`와 **같은 값**을 씁니다. GitHub 아이디도 같아서 구글 클라우드에서 새로 할 일은 거의 없습니다.

---

## 1단계. GitHub 저장소 만들기

1. https://github.com 에 로그인합니다.
2. 오른쪽 위 **+** → **New repository**를 누릅니다.
3. Repository name에 `ulsan-cce` 를 씁니다.
4. **Public**을 고릅니다. (Private이면 무료 GitHub Pages가 안 됩니다.)
5. 아래 **Create repository**를 누릅니다.
6. 만들어졌으면 Claude에게 "저장소 만들었어"라고 알려 주세요. 코드와 사진은 Claude가 올립니다.

## 2단계. GitHub Pages 켜기 (웹 화면 주소 만들기)

1. 저장소 화면 위쪽 **Settings**를 누릅니다.
2. 왼쪽 **Pages**를 누릅니다.
3. **Build and deployment → Branch**에서 `main` 과 `/docs` 를 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 같은 화면 위에 `https://xleesjx.github.io/ulsan-cce/inventory/` 주소가 나옵니다. 이 주소가 앱 주소입니다. 메모해 두세요.

## 3단계. 구글 시트와 Apps Script

1. 구글 드라이브에서 **새로 만들기 → Google Sheets → 빈 스프레드시트**를 누르고 이름을 `창의센터 물품·시설 관리`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 왼쪽 **⚙ 프로젝트 설정**에서 **"편집기에서 'appsscript.json' 매니페스트 파일 표시"**를 체크합니다.
4. 왼쪽 **< > 편집기**로 돌아와 파일 3개를 채웁니다. 파일 내용은 GitHub 저장소의 `apps/inventory/gas` 폴더에서 열어 **Raw** 버튼을 누르고 전체 복사(Ctrl+A, Ctrl+C)하면 됩니다.
   - `Code.gs`: 원래 있던 내용을 지우고 `apps/inventory/gas/Code.gs` 내용을 붙여넣습니다.
   - `+` → **스크립트** → 이름을 `Core`로 하고 `apps/inventory/gas/Core.gs` 내용을 붙여넣습니다.
   - `appsscript.json`: 내용을 지우고 `apps/inventory/gas/appsscript.json` 내용을 붙여넣습니다.
   - 💾 저장을 누릅니다.
5. 위쪽 함수 선택 칸에서 **`setupSheets`**를 고르고 **▶ 실행**을 누릅니다.
   - 권한 창이 뜨면 **권한 검토 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용**을 누릅니다. 직접 만든 스크립트라서 나오는 경고입니다.
6. 시트로 돌아가면 탭이 생겨 있습니다: `물품` `대여` `대여품목` `수리` `교실` `교실예약` `점검` `직원` `설정` `변경기록`
   - **직원** 탭에 내 계정이 들어가 있습니다. 이름을 고치고, 함께 쓸 선생님의 **구글 이메일과 이름**을 한 줄씩 추가합니다. 여기 없는 계정은 로그인이 안 됩니다.
   - **설정** 탭의 `센터전화`에 센터 전화번호를 적어 둡니다.
7. Apps Script **⚙ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**
   - 속성 `CLIENT_ID`, 값 `811907933210-o4ggim5o2qp330ctn6onqlriounsshf1.apps.googleusercontent.com` (`weekend-checker`와 같은 값)
8. Apps Script 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(⚙) → **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고, 나오는 **웹 앱 URL**(`…/exec`로 끝남)을 복사해 둡니다.

> "모든 사용자"로 열어도 안전합니다. 요청마다 구글 로그인을 확인하고, **직원 탭에 있는 계정만** 쓸 수 있습니다.

## 4단계. 화면에 서버 주소 연결

1. GitHub 저장소에서 `docs` 폴더 → `inventory` 폴더 → `config.js` 파일을 엽니다.
2. 오른쪽 위 ✏️(연필) 버튼을 누릅니다.
3. `API_URL:` 뒤의 글자를 지우고 3단계 8번에서 복사한 웹 앱 URL을 따옴표 안에 붙여넣습니다.
4. 오른쪽 위 **Commit changes**를 두 번 눌러 저장합니다.
5. 1~2분 뒤 앱 주소를 열고 구글 로그인을 해서 브리핑 화면이 나오면 성공입니다.

> 로그인이 안 되면: 구글 클라우드 → OAuth 동의 화면의 **테스트 사용자**에 직원 이메일이 있는지 확인합니다. (`weekend-checker`에서 이미 넣어 둔 분은 그대로 됩니다.)

## 5단계. 기존 자료 옮기기

Claude가 만들어 준 파일 3개를 순서대로 넣습니다.

### 5-1. 물품 목록 (`물품_가져오기.csv`)
1. 구글 시트 **물품** 탭을 누릅니다.
2. **파일 → 가져오기 → 업로드**에서 `물품_가져오기.csv`를 올립니다.
3. 가져오기 위치는 **현재 시트 바꾸기**를 고릅니다.
4. **"텍스트를 숫자, 날짜 및 수식으로 변환"은 체크를 끄고** **데이터 가져오기**를 누릅니다.
5. 앱을 새로고침하면 물품 대장에 보입니다.

### 5-2. 사진
사진 약 500장은 Claude가 `docs/inventory/photos` 폴더에 올립니다. (물품 대장 `사진` 칸의 파일 이름과 연결됩니다.)

### 5-3. 교실 예약 (`교실예약_가져오기.csv`)
확인표를 함께 보고 정리한 뒤에 넣습니다. 방법은 5-1과 같고 **교실예약** 탭에 가져옵니다.

### 5-4. 학교 목록
`weekend-checker` 구글 시트의 **설정_학교** 탭 첫 번째 열을 복사해 `학교목록.txt`로 저장하면, Claude가 `docs/inventory/schools.json`으로 만들어 올립니다.

## 6단계. 확인

1. 휴대폰 브라우저로 앱 주소를 열고 로그인합니다. (홈 화면에 추가해 두면 편합니다.)
2. 물품 대장에서 `드론`을 검색해 봅니다.
3. **대여 → + 새 대여**로 가짜 학교(예: 시험초등학교, 홍길동)를 등록하고 **지금 대여 → 서명 → 내주기 완료** 후 **반납 받기**까지 해 봅니다.
4. 시험으로 만든 대여는 시트 `대여`·`대여품목`·`수리` 탭에서 해당 줄을 지우면 됩니다. (물품 수량을 바꾼 분실·폐기 처리는 하지 마세요.)

## 문제가 생기면
| 증상 | 확인할 것 |
|---|---|
| "계정은 직원으로 등록되어 있지 않습니다" | 시트 `직원` 탭에 그 이메일이 있는지 |
| "스크립트 속성 CLIENT_ID가 없습니다" | 3단계 7번 |
| 화면이 계속 "불러오는 중" | `config.js`의 `API_URL`이 `/exec`로 끝나는지, 배포를 새로 했다면 주소가 바뀌지 않았는지 |
| 코드를 고친 뒤 반영이 안 됨 | Apps Script **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** |

## 업데이트 방법 (코드가 새로 나왔을 때)
화면(GitHub)은 저절로 최신이 됩니다. 서버(Apps Script)는 아래처럼 한 번 바꿔 줘야 합니다.
1. 시트 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs`와 `Core`의 내용을 지우고 GitHub의 최신 `apps/inventory/gas/Code.gs`, `Core.gs` 내용으로 바꿔 붙여넣은 뒤 💾 저장합니다.
3. 오른쪽 위 **배포 → 배포 관리 → ✏️(수정)** → **버전: 새 버전** → **배포**를 누릅니다. (웹 앱 URL은 그대로입니다.)
4. 앱을 새로고침합니다. 새 시트 탭(`센터사용`)과 새 설정 항목은 처음 불러올 때 **자동으로 만들어집니다.**
